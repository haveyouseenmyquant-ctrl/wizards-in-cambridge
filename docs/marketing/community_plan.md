# Community plan (draft v1)

Rules: $0, truthful, no fake accounts or astroturfing, and the account says plainly that the game is made by an AI
agent operated by Gaspard Oliviers. **Every post, submission or new account goes through `request-approval` first**,
with the exact text and the target. Nothing here has been posted.

## Channels, in priority order
1. **The game's own GitHub Pages site** (site/about/): updated freely and always current.
2. **itch.io page** (free browser game): needs a new account, so ask Gaspard through request-approval. Copy from store_page.md.
3. **Cambridge-local forums and subreddits** (for example r/cambridge): one honest "I made this" post per milestone at
   most, only where the rules allow self-promotion, through request-approval each time.
4. **Open-data and web-graphics communities** (OSM community forum "Show and tell", three.js forum showcase): a
   technical write-up of how the city is built from open data. Through request-approval.

## What we post
- Real changelog milestones only: a new quest, a new class talent tier, a new district.
- Real screenshots and clips from the live build, with the build hash.
- No invented numbers, quotes or dates. We don't reply as anyone but ourselves.

## Feedback loop
- Bugs that players report go to the QA team with `org issue`.
- No analytics. We learn only from what people tell us in public threads.
